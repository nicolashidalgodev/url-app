# firebase-app-1

This template should help get you started developing with Vue 3 in Vite.

## Firebase configuration

Copy `.env.example` to `.env.local` and fill in the Firebase web app values from
the Firebase console. `.env.local` is ignored by Git; do not commit real
credentials or service-account JSON files.

Firebase web API keys are included in the browser bundle and are not secrets.
Protect your project with Firestore Security Rules, Firebase App Check, and
appropriate API key restrictions in Google Cloud Console.
